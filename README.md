# Pizza Sales Dashboard 🍕

## Project Overview
This project is an interactive Pizza Sales Dashboard created using Microsoft Excel.

The dashboard helps analyze pizza sales performance using charts, pivot tables, and business insights.

---

## Features
- Total Sales Analysis
- Best Selling Pizzas
- Sales Trends
- Category-wise Performance
- Interactive Dashboard

---

## Excel Skills Used

- Data Cleaning
- Data Formatting

- Business Analysis
